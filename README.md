## Internship Tasks

### Task 1 – Data Visualization

**Dataset:** World Bank Population Dataset (Population, Total)

**Source:** [World Bank – Population, Total](https://data.worldbank.org/indicator/SP.POP.TOTL)

**Dataset File:** `API_SP.POP.TOTL_DS2_en_csv_v2_38144.csv`

**Objective:** Create visualizations to understand and analyse population data.

**Work Performed:**

- Loaded and inspected the population dataset.
- Checked missing values and dataset structure.
- Cleaned and prepared the data.
- Analysed population data.
- Created visualizations using Matplotlib and Seaborn.
- Identified patterns and trends through charts.

### Task 2 – Data Cleaning and Exploratory Data Analysis (EDA)

**Dataset:** Netflix Movies and TV Shows Dataset

**Source:** [Netflix Movies and TV Shows – Kaggle](https://www.kaggle.com/datasets/shivamb/netflix-shows)

**Objective:** Clean a dataset and explore its patterns, relationships and trends.

**Work Performed:**

- Inspected dataset structure and data types.
- Identified missing values and duplicate records.
- Performed data cleaning and preprocessing.
- Generated descriptive statistics.
- Explored variables using charts and visualizations.
- Analysed patterns and relationships in the data.

### Task 3 – Decision Tree Classification

**Dataset:** Bank Marketing Dataset

**Objective:** Build a Decision Tree Classifier to predict whether a customer will subscribe to a bank term deposit.

**Work Performed:**

- Loaded and explored the bank marketing dataset.
- Checked missing values and data types.
- Converted categorical variables into numerical values using Pandas.
- Separated input features (X) and target variable (y).
- Split data into training and testing sets (80:20).
- Trained a Decision Tree Classifier.
- Generated predictions and evaluated model performance.
- Visualized the decision tree.

**Model Details:**

- Algorithm: Decision Tree Classifier
- Maximum Depth: 5
- Random State: 42
- Reported Accuracy: Approximately 89.84%

### Task 4 – Social Media Sentiment Analysis

**Dataset:** Twitter Training Dataset

**Objective:** Analyse social media text and understand sentiment distribution across tweets.

**Work Performed:**

- Loaded and inspected the Twitter dataset.
- Identified missing values.
- Cleaned missing and duplicate records.
- Analysed Positive, Negative, Neutral and Irrelevant sentiments.
- Created sentiment distribution visualizations.
- Performed topic-wise sentiment analysis.
- Generated a Word Cloud to visualize frequently occurring words.

**Key Findings:**

- Initial dataset contained 74,682 records.
- After cleaning, 71,656 records remained.
- Negative sentiment had the highest initial count among the four sentiment categories.

### Task 5 – Traffic Accident Data Analysis

**Dataset:** US Accidents (2016–2023)

**Objective:** Analyse traffic accident records and identify patterns based on severity, weather conditions, time and location.

**Work Performed:**

- Downloaded the dataset using the Kaggle API.
- Inspected dataset structure and data types.
- Identified and handled missing values.
- Analysed accident severity distribution.
- Explored accidents by time of day.
- Analysed weather conditions during accidents.
- Identified the top 10 states with the highest accident counts.
- Created visualizations using Matplotlib.

**Key Findings:**

- California recorded the highest number of accidents in the state-wise analysis.
- Florida and Texas followed California.
- Evening had the highest accident count among the displayed time-of-day categories.
- Clear weather was the most frequently recorded weather condition in the analysed sample.
